## 9. 残余风险与交付定位

- 原生 Gate 运行于 GitHub `windows-2025`（Windows Server 2025 AMD64），不是字面上的干净 Windows 10/11 VM。它证明 AMD64 构建、断网 payload 执行、安装/升级/卸载和数据保留；首次真实 Windows 10/11 自用安装仍应按 `INSTALL.md` 做发布前人工烟测。
- Runner 可能已有系统级 WebView2；测试仍在 payload 进程被阻断全部出站时执行 standalone installer 并验证 runtime registration，但不把该事实描述为“已证明完全无预装 runtime 的干净 VM”。
- 未签名 installer 会触发 SmartScreen/unknown publisher，Smart App Control 或组织策略可能不给出 `Run anyway`；这种设备准确标记为 unsupported，不提供策略绕过。
- 当前 artifact 是 14 天保留的 Actions evidence，不是长期发布渠道；外部 publish 前仍需单独批准发布位置、版本、保留策略，并完成上述 Windows 10/11 人工烟测。
- Evergreen fwlink 内容未来会变化；identity 以精确 size/SHA-256 fail closed，payload 更新必须显式更新版本证据后重新跑完整 Gate。
