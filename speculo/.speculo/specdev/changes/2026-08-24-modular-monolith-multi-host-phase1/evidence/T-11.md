## 8. 偏差与决策

- **偏差：** `DEV-001` / spec + release。用户于 2026-08-25 明确批准 Phase 1 macOS/Windows 正式桌面产物采用 unsigned self-use，以自有设备可安装可用优先；平台可信签名、公证与 Store 分发延期。
- **安全收敛：** 用户必须先验证 SHA-256，只对已校验的单 App 建立例外；文档禁止全局关闭 Gatekeeper。受管设备策略阻断时报告不支持，不绕过管理策略。
- **批准边界：** implementation commit/push/verification dispatch 已授权；GitHub Release/external publish、deploy 与 production migration 仍未授权。

## 9. 残余风险与交付定位

- 未签名 App 会显示未知开发者警告，且系统策略或受管设备可能不允许用户例外；这是准确声明的 Phase 1 产品限制。
- 当前 artifact 是 14 天保留的 Actions evidence，不是长期发布渠道；对外 publish 前仍需单独批准发布位置、版本和保留策略。

- 未来启用 Developer ID/notary 时须新 release 偏差、批准 identity 和 secret 注入，并重新执行 signed clean-machine 矩阵；不回写或伪装本次 self-use trust state。
