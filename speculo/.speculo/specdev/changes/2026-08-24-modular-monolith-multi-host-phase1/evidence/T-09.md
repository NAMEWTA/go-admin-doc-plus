## 1. 实现摘要

- 新增 `internal/platform/desktop`：macOS Application Support、Windows LocalAppData 数据根解析，以及 macOS/Linux `flock`、Windows `LockFileEx` 的 OS 级单实例锁。
- Runtime 在打开业务 SQLite 前持锁，复用 T-03 `UpgradeDesktop` 完成备份和事务化 migration；失败返回可恢复 backup path，成功后才构建 Application/UI，关闭时按 HTTP -> Application -> adapters -> owned logger -> instance lock 逆序释放。
- Host 同时验证 listener address 与 request remote address 必须为 loopback，继续校验精确 Wails Origin 和每启动随机 token；错误响应 `no-store`，bootstrap 暴露稳定 security policy。
- Desktop FileStore 继续复用 `os.Root` 沙箱；新增持久化重启、遍历拒绝和跨进程单实例测试。
- 原生测试补充当前 OS 平台目录、实际非 loopback LAN 网卡不可达，以及在途 HTTP 请求完成后才停止 Application/Runtime 的严格关闭顺序；点对点 TUN 不作为 LAN 网卡。
- Windows 原生失败先后暴露并修复 `app.log` 句柄未关闭与 POSIX directory `fsync` 不适用于 Windows；文件内容仍逐个 `Sync+Close`，Unix 继续同步 backup directory，Windows 在文件持久化后发布 backup path。
- Windows tracer 直接运行 profile/platform/host/native hardening tests，随后构建固定 SHA Wails AMD64 应用并执行真实 WebView login/getinfo/demo CRUD。
