## 1. 实现摘要

产品命令面收敛为单一 `go-admin-plus` 二进制及 `serve/worker/migrate/bootstrap/recover-admin/doctor/version` 七个子命令，删除旧 `cmd/migrate` 与 `cmd/config-check`。PostgreSQL API、worker、migration 所有权显式分离；SQLite/dev 支持 `serve --with-worker`，并以数据根实例锁阻止运行时与恢复类命令竞态。运行时按组合 migration FS 精确验证 schema，Server SQLite 自动迁移，PostgreSQL 仅允许显式迁移。产品 worker composition 接入 scheduler、outbox、账号删除生命周期与 Files reconcile，API-only 角色不持有 worker lease。
