## 1. 实现摘要

Desktop native runner 现在是 required/non-skip：缺少 `GO_ADMIN_DESKTOP_NATIVE_E2E=1`、非 macOS、任一 phase 失败或缺少最终精确 marker 均非零。artifact path 按目标平台使用确定性的 POSIX/Windows path API，并根据 macOS `arm64/x64` 动态选择 sidecar triple。production verifier 对相关 Tauri config/capability 做精确键集合与值校验，包括唯一隐藏 `main-window`、`960x640` 最小尺寸、禁用 devtools、无 remote origin、单一 sidecar、精确 13 项 command capability allowlist 与 production byte marker；反向测试会拒绝远程来源、权限增长、可见启动窗口或 devtools。

真实窗口路线新增两类空库首次设置：正常 setup 后以 Stronghold Session 重启；以及在临时 Stronghold snapshot/父目录注入只读故障，使管理员已提交而 vault 写入失败，观察恢复 UI、恢复临时权限并以合法隔离 Keychain account 重启登录。窗口 frame 在 setup 与 workspace 要求至少 `960x640`，全部表单通过聚焦原生 AX submit button 后发送 Enter 键提交。既有 migration failure、登录、权限/数据范围、Session revoke/relogin、单实例、CRUD、SQLite 停机验证、Stronghold restart、logout restart、loopback、production marker、进程/Keychain/临时目录清理继续保留。
