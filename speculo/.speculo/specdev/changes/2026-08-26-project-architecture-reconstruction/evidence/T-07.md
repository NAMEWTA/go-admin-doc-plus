## 1. 实现摘要

新增双方言 IAM Administration schema、用户/角色/菜单/Permission Code 管理、`all/self` 数据范围、数据库最终授权、保护对象约束和即时 manifest 投影。Session 通过统一 `AuthorizeRequest` 接缝提供 token、CSRF、touch 与 rotation 语义；前端以 headless domain + Web domain 页面完成搜索、CRUD、授权分配、密码重置、单删/批删、确认和写后修复，不把 UI 可见性当作授权边界。

权限判定每次读取数据库事实；PostgreSQL 在最终授权与受保护写入间持有贡献行锁，SQLite 使用同一语义查询。全局角色、菜单和 Permission Code 元数据对 `self` scope fail closed；稳定业务键、页码上限、非空约束、保护角色/菜单/管理员和公共 Problem JSON 均由合同与数据库共同约束。
