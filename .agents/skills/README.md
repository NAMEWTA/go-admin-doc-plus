# Go Admin Plus Project Skills

This directory contains the project-specific engineering skills for the Go Admin Plus monorepo.

| Skill | Scope |
|---|---|
| [backend-development](backend-development/SKILL.md) | Go server, modular application composition, migrations, transport and backend quality gates |
| [frontend-development](frontend-development/SKILL.md) | Vue 3, TypeScript, pnpm workspace, Web/Desktop composition and UI quality gates |
| [new-business-module](new-business-module/SKILL.md) | A new backend/frontend CRUD vertical slice |
| [new-list-page](new-list-page/SKILL.md) | A standard CRUD list and management page |

Read the applicable platform skill before using a task-specific skill. The two platform skills describe
the current architecture; task-specific skills describe the smallest safe change workflow.
